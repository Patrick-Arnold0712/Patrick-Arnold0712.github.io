复现命令与目录结构

零依赖六步复现 & 本地五步向导

核心链路需要 Node.js 18+，无需 npm install。向导服务运行于 http://127.0.0.1:7788。

# 六步基础复现与测试
node scripts/reproduce.js
npm test

# 启动本地五步交互向导 / 单独生成
npm run wizard
npm run generate:led
npm run generate:rc

工程目录与边界声明

  • src/：生成器、规则/契约校验、器件参数、向导与客户端回读
  • test/ & contracts/jsonschema/：自动测试与三套 JSON Schema 契约
  • scripts/reproduce.js & audit.js：六步复现与电气/BOM 审计
  • vendor/：保留原版上游及 MIT 许可证，与实验代码严格隔离
