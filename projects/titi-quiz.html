系统技术架构

01 / INPUT

多格式解析

PDF / DOCX / MD / TXT / 图片分科导入与校对

02 / ENGINE

本地 RapidOCR

离线提取扫描件文本，单 PDF 上限 256 MiB / 1000 页

03 / BACKEND

FastAPI + SQLite

轻量单机后端与 /docs API 文档，附带自动化自检脚本

04 / FRONTEND

Vue 3 + Vite 6

响应式交互界面，电脑端整理资料、手机端随时刷题

本地快速启动（本机单人使用）

需要 Python 3.10+ 与 Node.js 22（Windows PowerShell） 
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r backend/requirements-ocr.txt
npm --prefix frontend ci
npm --prefix frontend run build:only
.venv\Scripts\python.exe -m uvicorn app.main:app --app-dir backend --host 127.0.0.1 --port 8000

启动后访问 http://127.0.0.1:8000（API 文档在 /docs）。运行 python tools/selftest_material_import.py 可使用临时库自检 OCR 与判分流程。
